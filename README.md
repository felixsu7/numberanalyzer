# numberanalyzer

A program that tests numbers for various properties. For a college project.

## Features

- Basic text-based UI
- Text colors and styles ~if windows is nice~
- TUI Mode ~again, if windows is nice~
- Expression parser for decent calculator functionality

### Properties to be tested
1. Positive/negative/zero
2. Even/odd
3. Divisibility by selected integers
4. Factors
5. Number of factors
6. Prime or composite
7. Sum of factors
8. Perfect number

*The following are our ideas and may not end up in the final output.*

9. Collatz conjecture *(how many iterations before ending in the infinite loop)*
10. Prime factorization
11. Perfect Square/Cube
12. Triangular number
